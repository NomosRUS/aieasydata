## 🚀 ПРАКТИЧЕСКИЕ ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ

### 1. Анализ CSV файла
```bash
curl -X POST "http://localhost:8000/api/v1/performance/analyze" \
  -H "Content-Type: application/json" \
  -d '{"source": "temp_sales.csv"}'
```

**Результат:**
```json
{
  "analysis_id": "analysis_20250925_175246_099426",
  "source": "temp_sales.csv",
  "source_type": "csv",
  "status": "completed",
  "current_metrics": {
    "data_size_bytes": 0,
    "row_count": 0,
    "source_type": "csv"
  },
  "recommendations": []
}
```

### 2. Получение метрик файла
```bash
curl "http://localhost:8000/api/v1/performance/metrics/temp_sales.csv"
```

**Результат:**
```json
{
  "source": "temp_sales.csv",
  "source_type": "csv",
  "metrics": {
    "data_size_bytes": 0,
    "row_count": 0
  },
  "analysis_id": "analysis_..."
}
```

### 3. Валидация DDL скрипта
```bash
curl -X POST "http://localhost:8000/api/v1/performance/validate-ddl" \
  -d "ddl_script=CREATE TABLE test (id INT);" \
  -d "target_db_type=postgres"
```

**Результат:**
```json
{
  "valid": true,
  "errors": [],
  "target_db_type": "postgres"
}
```
