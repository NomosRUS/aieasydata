# ЗАДАЧА 8: Разработка ИИ-агента для консультирования и управления системой

**Исполнитель**: Команда разработчиков  
**Ветка Git**: `feature/ai-agent`  
**Расположение модуля**: `backend/app/ai_agent/`

## **1. Цель и концепция**

Разработать интеллектуального агента `ai_agent`, который консультирует пользователей и автоматически управляет выполнением всех функций системы. Агент будет выполнять четыре ключевые функции:

1. **Консультирование пользователей**: Анализ запросов и предоставление рекомендаций по обработке данных
2. **Автоматическое управление модулями**: Запуск и координация выполнения модулей 1,2,3,4,5
3. **Генерация DAG'ов**: Создание Airflow пайплайнов на основе пользовательских требований
4. **Мониторинг и оптимизация**: Непрерывное улучшение процессов на основе результатов

**Уровень реализации**: **Базовый**. Основной фокус — на создании работающего агента с базовыми возможностями консультирования и управления.

## **2. Архитектурное место в системе**

- Все новые файлы для этого модуля будут размещаться в директории: `backend/app/ai_agent/`
- Агент интегрируется со всеми модулями через их HTTP API
- Использует LLM для анализа запросов и генерации рекомендаций
- Является центральным координатором всей системы

## **3. Компоненты ИИ-агента**

### **3.1. Анализатор запросов (Query Analyzer)**
- **Функция**: Понимание естественного языка пользователя
- **Технология**: LLM (OpenAI GPT или локальная модель)
- **Выход**: Структурированное представление задачи

### **3.2. Планировщик задач (Task Planner)**
- **Функция**: Создание плана выполнения на основе анализа
- **Логика**: Определение последовательности модулей и параметров
- **Выход**: Исполняемый план с API вызовами

### **3.3. Исполнитель (Executor)**
- **Функция**: Выполнение плана через вызовы API модулей
- **Мониторинг**: Отслеживание прогресса и обработка ошибок
- **Выход**: Результаты выполнения и отчеты

### **3.4. Генератор DAG'ов (DAG Generator)**
- **Функция**: Создание Airflow пайплайнов для регулярного выполнения
- **Шаблоны**: Использование готовых шаблонов DAG'ов
- **Выход**: Python файлы DAG'ов для Airflow

## **5. Основные классы и функции**

### **5.1. AgentOrchestrator (main.py)**
**Назначение:** Главный класс агента, координирующий все компоненты

#### `process_user_request(request: str, context: dict) -> AgentResponse`
**Назначение:** Обработка пользовательского запроса от начала до конца

**Входные параметры:**
```python
{
    "request": "Мне нужно загрузить CSV файл с продажами в ClickHouse с партиционированием по датам",
    "context": {
        "user_id": str,
        "session_id": str,
        "previous_requests": List[str],
        "available_data_sources": List[str]
    }
}
```

**Выходные данные:**
```python
AgentResponse = {
    "response_id": str,
    "user_message": str,  # Ответ пользователю
    "execution_plan": ExecutionPlan,
    "estimated_time": int,  # в минутах
    "confidence": float,  # 0.0 - 1.0
    "alternatives": List[ExecutionPlan],
    "dag_generated": bool,
    "dag_path": Optional[str]
}
```

### **5.2. QueryAnalyzer (query_analyzer.py)**
**Назначение:** Анализ и понимание запросов пользователя

#### `analyze_query(query: str) -> QueryAnalysis`
**Назначение:** Извлечение структурированной информации из запроса

**Выходные данные:**
```python
QueryAnalysis = {
    "intent": "data_loading|data_analysis|optimization|monitoring",
    "entities": {
        "source_format": Optional[str],  # csv, json, xml
        "target_database": Optional[str],  # postgresql, clickhouse, hdfs
        "data_size": Optional[str],  # small, medium, large
        "requirements": List[str]  # partitioning, indexing, etc.
    },
    "complexity": "simple|medium|complex",
    "required_modules": List[int],  # [1, 4, 5]
    "confidence": float
}
```

### **5.3. TaskPlanner (task_planner.py)**
**Назначение:** Создание плана выполнения задач

#### `create_execution_plan(analysis: QueryAnalysis) -> ExecutionPlan`
**Назначение:** Генерация последовательности действий

**Выходные данные:**
```python
ExecutionPlan = {
    "plan_id": str,
    "steps": List[ExecutionStep],
    "estimated_duration": int,
    "dependencies": dict,
    "rollback_plan": List[str]
}

ExecutionStep = {
    "step_id": str,
    "module": int,  # номер модуля
    "action": str,  # API endpoint
    "parameters": dict,
    "expected_output": str,
    "timeout": int,
    "retry_count": int
}
```

### **5.4. Executor (executor.py)**
**Назначение:** Выполнение планов через API вызовы

#### `execute_plan(plan: ExecutionPlan) -> ExecutionResult`
**Назначение:** Последовательное выполнение всех шагов плана

**Мониторинг выполнения:**
- Отслеживание прогресса каждого шага
- Обработка ошибок и retry логика
- Сбор метрик производительности
- Уведомления о статусе

### **5.5. DAGGenerator (dag_generator.py)**
**Назначение:** Генерация Airflow DAG'ов для автоматизации

#### `generate_dag(plan: ExecutionPlan, schedule: str) -> str`
**Назначение:** Создание Python файла DAG'а

**Шаблоны DAG'ов:**
- Ежедневная обработка данных
- Еженедельная оптимизация
- Мониторинг в реальном времени
- Пользовательские расписания

## **6. Интеграция с LLM**

### **6.1. LLMClient (llm_client.py)**
**Назначение:** Взаимодействие с языковой моделью

```python
class LLMClient:
    def __init__(self, model_type: str = "openai"):
        # Поддержка OpenAI API или локальных моделей
        pass
    
    def analyze_user_query(self, query: str, context: dict) -> dict:
        """Анализ пользовательского запроса через LLM"""
        prompt = self._build_analysis_prompt(query, context)
        response = self._call_llm(prompt)
        return self._parse_analysis_response(response)
    
    def generate_explanation(self, plan: ExecutionPlan) -> str:
        """Генерация объяснения плана для пользователя"""
        prompt = self._build_explanation_prompt(plan)
        return self._call_llm(prompt)
    
    def suggest_optimizations(self, execution_history: List[dict]) -> List[str]:
        """Предложение оптимизаций на основе истории"""
        prompt = self._build_optimization_prompt(execution_history)
        return self._call_llm(prompt)
```
