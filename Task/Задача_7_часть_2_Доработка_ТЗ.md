### **4.1. Обязательные правила избегания ошибок**

**Из ERROR_FIXES_REPORT.md:**

**1. Плейсхолдеры:**
```json
// ✅ ПРАВИЛЬНО: Простые плейсхолдеры

    "source_profile_id": "{{ step_1_output.id }}"
}

// ❌ НЕПРАВИЛЬНО: Сложные выражения

    "source_profile_id": "{{ step_1_output.data.profile.id }}"
}
```

**2. Типы данных:**
```json
// ✅ ПРАВИЛЬНО: Использование save_to для передачи данных
{
    "step": 1,
    "save_to": "step_1_output"
}

// ❌ НЕПРАВИЛЬНО: Прямая передача сложных объектов
```

**3. Уникальность записей:**
```json
// ✅ ПРАВИЛЬНО: Динамические имена
"payload": {
    "name": "test_scenario_{{ timestamp }}"
}

// ❌ НЕПРАВИЛЬНО: Статические имена
"payload": {
    "name": "test_scenario"
}
```

**4. Существующие эндпоинты:**
```json

**5. Таймауты для долгих операций:**

}
```
