# AiEasyData: Интеллектуальный Профилировщик Данных

Это веб-приложение для автоматического профилирования и анализа различных источников данных с использованием LLM (Large Language Model).

Система сканирует указанные директории, определяет тип данных (CSV, JSON, XML, Parquet), собирает метаданные и статистику, а затем отправляет эту информацию в LLM для получения краткого аналитического резюме на естественном языке.

## Основные возможности

- **Автоматическое профилирование:** Система самостоятельно находит и анализирует файлы в `data_landing_zone`.
- **Поддержка разных форматов:** Корректно работает с CSV, JSON, JSONL, XML и Parquet.
- **LLM-анализ:** Генерирует описание набора данных, выделяет ключевые сущности и поля, предлагает возможные направления для анализа.
- **Интерактивный UI:** Позволяет просматривать каталог обнаруженных источников данных и вручную запускать процесс профилирования.
- **Оркестрация через Airflow:** Все процессы обработки данных управляются и выполняются как DAG'и в Apache Airflow.

## Технологический стек

- **Backend:** FastAPI (Python)
- **Frontend:** React (Vite)
- **Оркестрация:** Apache Airflow
- **Базы данных:** PostgreSQL (для метаданных), ClickHouse (для данных)
- **Инфраструктура:** Docker, Docker Compose

## Инструкция по запуску

### Шаг 1: Предварительные требования

Убедитесь, что на вашем компьютере установлены:

1.  **Docker** и **Docker Compose**
2.  **Git**

### Шаг 2: Клонирование репозитория

Откройте терминал и выполните команду:

```bash
git clone https://github.com/NomosRUS/aieasydata.git
cd aieasydata
```

### Шаг 3: Настройка переменных окружения

1.  Найдите в корне проекта файл `.env.example`.
2.  Создайте его копию и назовите ее `.env`.
3.  Откройте файл `.env` и вставьте ваш API-ключ от OpenAI:

    ```
    OPENAI_API_KEY=sk-...
    ```

### Шаг 4: Запуск проекта

В корневой директории проекта выполните команду:

```bash
docker-compose up --build -d
```

Эта команда соберет все образы и запустит все сервисы в фоновом режиме. Первый запуск может занять несколько минут.

### Шаг 5: Использование приложения

1.  **Добавьте данные:** Поместите ваши файлы с данными (CSV, JSON и т.д.) в папку `data_landing_zone`.
2.  **Откройте UI:** Перейдите в браузере по адресу [http://localhost:3000](http://localhost:3000).
3.  **Запустите профилирование:** Нажмите кнопку **"Актуализировать каталог"**. Это запустит DAG в Airflow, который найдет и проанализирует ваши файлы.
4.  **Просмотрите результат:** Через некоторое время на странице появятся карточки с описанием ваших источников данных.

### Доступ к сервисам

- **Веб-интерфейс:** [http://localhost:3000](http://localhost:3000)
- **Airflow UI:** [http://localhost:8080](http://localhost:8080) (логин: `admin`, пароль: `admin`)
- **Документация API:** [http://localhost:8000/docs](http://localhost:8000/docs)
