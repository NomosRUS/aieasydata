1.  **Гонка состояний (Race Condition):**
    - **Гипотеза:** Модуль 4 (Warehouse) отправляет ответ `200 OK` до того, как транзакция на создание `WarehouseInstance` полностью зафиксирована в базе данных.     - **Решение:** Внедрить механизм `retry` с небольшой задержкой на стороне клиента (в `ScenarioEngine`) или обеспечить, чтобы API Модуля 4 отвечал только после полной фиксации транзакции.

2.  **Ошибка в передаче/интерпретации `design_id`:**
    - **Гипотеза:** Несмотря на то, что `design_id` выглядит как корректный UUID, он может передаваться между модулями с искажениями (например, с лишними кавычками или как часть более сложной строки). Pydantic-модель на стороне Модуля 5 может некорректно парсить такой ID, что приводит к неудачному поиску в базе.
    - **Решение:** Добавить подробное логирование на стороне Модуля 5, чтобы проверить точное значение и тип `design_id`, которое он получает.

3.  **Рассинхронизация конфигураций или кэширование:**
    - **Гипотеза:** Модуль 4 и Модуль 5, хотя и должны работать с одной базой метаданных, могут быть случайно сконфигурированы для работы с разными экземплярами БД (например, `db` и `test_db` в Docker). Также возможно наличие агрессивного слоя кэширования (хотя маловероятно для прямого запроса по ID), который возвращает устаревшие данные.
    - **Решение:** Проверить переменные окружения и конфигурационные файлы обоих модулей, чтобы убедиться, что они используют идентичные строки подключения к базе данных.

### **1. ✅ ПЛЕЙСХОЛДЕРЫ - ПОЛНОСТЬЮ ИСПРАВЛЕНО**

**Проблема:** Неудачное разрешение плейсхолдеров `{{ step_output.field }}`
```python
# БЫЛО: Ошибки KeyError при разрешении плейсхолдеров
Could not resolve placeholder '{{step_6_output.id}}': Key 'id' not found
```

**Решение:** Улучшенная система разрешения с логированием
```python
def _interpolate(self, data: str) -> str:
    def replacer(match):
        expression = match.group(1).strip()
        keys = expression.split('.')
        value = self.step_outputs

        logger.debug(f"Resolving placeholder '{{{{{expression}}}}}' with keys: {keys}")
        logger.debug(f"Available step_outputs keys: {list(self.step_outputs.keys())}")

        try:
            for i, key in enumerate(keys):
                logger.debug(f"Step {i}: key='{key}', current_value_type={type(value)}")
                if isinstance(value, dict):
                    if key in value:
                        value = value[key]
                        logger.debug(f"Found dict key '{key}': {type(value)}")
                    else:
                        logger.debug(f"Dict key '{key}' not found in {list(value.keys())}")
                        raise KeyError(f"Key '{key}' not found in step outputs")
                elif isinstance(value, list):
                    value = value[int(key)]
                    logger.debug(f"Accessed list index {key}: {type(value)}")
                else:
                    raise KeyError(f"Cannot access key '{key}' in non-dict/list value")

            result = str(value)
            logger.debug(f"Successfully resolved to: {result}")

            # Попытка конвертации в число, если это возможно
            try:
                if '.' in result:
                    return float(result)
                else:
                    return int(result)
            except ValueError:
                return result
        except (KeyError, IndexError, TypeError, ValueError) as e:
            logger.warning(f"Could not resolve placeholder '{{{{{expression}}}}}': {e}")
            logger.warning(f"Available step outputs: {self.step_outputs}")
            return match.group(0)  # Возвращаем исходный плейсхолдер

    return re.sub(r'\{\{(.+?)\}\}', replacer, data)
```

**Результат:** ✅ Плейсхолдеры корректно разрешаются, автоматическая конвертация в числа

class ExternalAPIClient:
    async def _ensure_session(self):
        """Создает сессию, если она еще не существует."""
        if not self.session:
            self.session = aiohttp.ClientSession(timeout=self.timeout)
    
    async def call_api(self, endpoint: str, method: str = "GET", ...):
        await self._ensure_session()
        # ... остальная логика

        """Закрывает HTTP сессию."""

            await self.session.close()
            self.session = None
