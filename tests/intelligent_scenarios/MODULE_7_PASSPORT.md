### **Реальная структура и поток данных:**
```
tests/intelligent_scenarios/
├── scenario_engine.py       # ✅ 1. Исполняет сценарии из scenarios/
├── scenarios/               # ✅ 2. Содержит JSON-описания тестов
├── utils/                   #
│   └── trajectory_recorder.py # ✅ 3. Записывает успешный результат...
└── knowledge_base/
    └── successful_trajectories/ # ✅ 4. ...в эту директорию.

# Компоненты, требующие реализации:
tests/intelligent_scenarios/
├── ai_trainer.py            # ❌ 5. Должен читать данные из knowledge_base и готовить их для ИИ.
└── reports/                 # ❌ 6. Должны генерироваться HTML-отчеты.
```
