## 🛠️ ОСНОВНЫЕ ВОЗМОЖНОСТИ

### Анализ производительности:
- Автоматическое определение типа данных (любой источник)
- Выявление узких мест производительности
- LLM-анализ с обоснованиями
- Поддержка файлов, директорий, БД, существующих хранилищ

### Генерация рекомендаций:
- **PARTITION** - партиционирование для больших таблиц
- **INDEX** - индексы для ускорения запросов
- **COMPRESSION** - сжатие данных
- **ORDER_BY** - оптимальная сортировка (ClickHouse)
- **RESTRUCTURE** - изменение формата данных

### DDL-генерация для всех СУБД:
```sql
-- ClickHouse
PARTITION BY toYYYYMM(sale_date)
ORDER BY (sale_date, customer_id)

-- PostgreSQL
CREATE INDEX idx_table_column ON table(column);
PARTITION BY RANGE (date_column)

-- HDFS
PARTITIONED BY (year_month)
STORED AS PARQUET
COMPRESSION 'snappy'
```
