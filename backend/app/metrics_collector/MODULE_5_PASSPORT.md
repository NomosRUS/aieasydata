## 🧠 СИСТЕМА АВТООПРЕДЕЛЕНИЯ ТИПОВ ДАННЫХ

### Класс DataTypeDetector

Интеллектуальная система, которая может определить:

1. **Файлы и директории:**
   - Анализ расширений файлов
   - Определение доминирующего типа в директории
   - Анализ содержимого для неизвестных расширений

2. **Базы данных:**
   - Распознавание строк подключения PostgreSQL
   - Распознавание строк подключения ClickHouse
   - Автоматическое извлечение параметров подключения

3. **Структурный анализ:**
   - CSV: автоопределение разделителей
   - JSON: различение JSON/JSON Lines
   - XML: определение тегов записей

### Примеры автоопределения:

```python
# Директория с файлами
detector.detect_data_type("/data/syn_csv")
# Результат: {'type': 'directory', 'dominant_type': 'csv', 'total_files': 12}

# Строка подключения к БД  
detector.detect_data_type("postgresql://user:pass@localhost:5432/db")
# Результат: {'type': 'database', 'db_type': 'postgresql', 'connection_available': True}

# Отдельный файл
detector.detect_data_type("/path/to/data.json")
# Результат: {'type': 'file', 'file_type': 'json', 'format': 'json_array'}
```
