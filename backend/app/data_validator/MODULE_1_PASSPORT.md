## 🧠 АЛГОРИТМЫ И ЛОГИКА

### Алгоритм оценки качества данных:
```python
quality_score = (
    completeness * 0.4 +      # 40% - полнота данных
    correctness * 0.3 +       # 30% - корректность типов
    consistency * 0.2 +       # 20% - согласованность
    uniqueness * 0.1          # 10% - уникальность
)
```

### Алгоритм выбора СУБД:
- **quality_score < 0.7** → HDFS (для "грязных" данных)
- **quality_score >= 0.7 + analytics_patterns** → ClickHouse
- **quality_score >= 0.8 + transactional_patterns** → PostgreSQL
- **По умолчанию** → PostgreSQL

### Алгоритм проверки однородности:
1. Сканирование всех файлов в папке
2. Извлечение схемы каждого файла (колонки, типы, разделители)
3. Сравнение с эталонной схемой
4. Автоматическое создание папки `{folder}_inconsistent/`
5. Перемещение неоднородных файлов с отчетом
